# Catalogue imagery

This is demonstration inventory, not live stock or verified offers. Prices, ratings,
review counts and specifications are sample data. Generic sample-brand names do not
represent a manufacturer endorsement. Do not use this seed catalogue as a sales feed.

- New kitchen, fashion, beauty and sports photos: public DummyJSON sample catalogue,
  downloaded locally. Exact URLs are in `catalogue-sources.json`.
- Classic book cover illustrations: Project Gutenberg, exact URLs in the same manifest.
  These illustrate the titles; they do not identify a particular print edition.
- Existing electronics photography: Unsplash illustrative images retained from the
  original prototype. These are not verified photographs of the named models.
- `parallel-hero.png`: generated studio illustration retained from the prototype.
- `product-unavailable.svg`: local neutral fallback, used only when an image fails.

Product-page and footer disclosures distinguish illustrative/sample content from real offers.
